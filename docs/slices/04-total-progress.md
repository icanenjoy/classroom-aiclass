# 기능 4: 사용자가 지금까지 총 몇 문제를 풀었는지 볼 수 있다

## 완료 조건
- [x] 화면에 "지금까지 총 N문제 풀었음"이 보인다
- [x] 문제를 하나 더 풀면 숫자가 바로 갱신된다

## 계산 방식 (여러 번 수정됨 — 최종)
1차: localStorage 전체 시도 기록에서 고유 문제 수를 셈 → 문제 발생: "다시 풀기"를 눌러도 예전 기록이 남아있어서, 20문제를 다 풀고 나면 숫자가 계속 20에 멈춰있는 것처럼 보임 (사용자가 "하드코딩된 것 같다"고 지적)

최종: **localStorage를 안 쓰고, 지금 진행 중인 메인 흐름 + 그 브랜치들의 상태에서 직접 계산**
- `mainResults`(메인 20문제)와 `branches`의 각 문제 결과 중 답변된(`!== null`) 것의 문제 id를 Set으로 모아 개수를 셈 (브랜치 포함, 같은 문제 중복 카운트 안 됨)
- 페이지를 새로고침하거나 "다시 풀기"를 누르면 상태가 초기화되므로 숫자도 자연스럽게 0부터 다시 시작함

## 기능 1과의 관계 변경
기능 1의 완료 조건("새로고침해도 기록이 안 사라진다")은 **localStorage 저장 자체**(`addAttempt`)에는 여전히 적용됨 — 시도 기록은 계속 쌓임. 다만 기능 4의 화면 숫자는 이제 그 기록이 아니라 "지금 이 판"의 진행 상황만 보여주는 것으로 바뀜. 저장된 기록을 앞으로 다른 용도로 쓸지는 미정.
