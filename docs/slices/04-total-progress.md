# 기능 4: 사용자가 지금까지 총 몇 문제를 풀었는지와 정답률을 볼 수 있다

## 완료 조건
- [x] 화면에 "지금까지 총 N문제 풀었음"이 보인다
- [x] 정답률(%)이 함께 보인다
- [x] 문제를 하나 더 풀면 숫자가 바로 갱신된다

## 계산 방식 (사용자 확인됨)
- N = 브랜치 문제를 포함한 **고유 문제 수**. 같은 문제를 재시도해도 N에는 한 번만 카운트
- 정답률 = 각 문제의 **마지막 시도** 기준 정답 개수 / N (재시도해서 나중에 맞히면 정답으로 반영됨)
- `src/lib/storage.ts`의 `getStats()`가 계산: attempts 로그(append-only)를 questionId로 묶어 마지막 값만 남김

## 건드릴 파일
- `src/lib/storage.ts` — `getStats()` 추가
- `src/app/sqld/page.tsx` — 헤더를 세션 카운트 대신 누적 통계로 교체, 제출할 때마다 갱신

## 확인 방법
- 문제 하나 풀면 헤더 숫자가 바로 바뀌는지
- 같은 문제를 브랜치로 다시 풀어도 총 N이 늘지 않는지 (재시도 제외 확인)
- 새로고침해도 숫자가 유지되는지 (localStorage 기반이라 유지되어야 함)
