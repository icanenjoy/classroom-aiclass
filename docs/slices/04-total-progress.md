# 기능 4: 사용자가 지금까지 총 몇 문제를 풀었는지 볼 수 있다

## 완료 조건
- [x] 화면에 "지금까지 총 N문제 풀었음"이 보인다
- [x] 문제를 하나 더 풀면 숫자가 바로 갱신된다

## 계산 방식 (사용자 확인됨)
- N = 브랜치 문제를 포함한 **고유 문제 수**. 같은 문제를 재시도해도 N에는 한 번만 카운트
- 정답률은 필요 없다고 확인되어 표시하지 않음 (처음엔 넣었다가 뺌)
- `src/lib/storage.ts`의 `getSolvedCount()`가 계산: attempts 로그에서 questionId를 Set으로 묶어 개수만 셈

## 건드릴 파일
- `src/lib/storage.ts` — `getSolvedCount()`
- `src/app/sqld/page.tsx` — 헤더에 총 문제 수만 표시, 제출할 때마다 갱신

## 확인 방법
- 문제 하나 풀면 헤더 숫자가 바로 바뀌는지
- 같은 문제를 브랜치로 다시 풀어도 총 N이 늘지 않는지 (재시도 제외 확인)
- 새로고침해도 숫자가 유지되는지
