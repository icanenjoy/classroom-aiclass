# 기능 3: 왼쪽에서 메인 흐름과 브랜치를 볼 수 있다

## 완료 조건
- [x] 왼쪽 사이드바에 메인 흐름(1~20) 목록이 보이고, 지금 위치가 표시된다
- [x] "더 풀기"로 브랜치를 만들면, 그 브랜치가 스폰된 메인 문제 아래에 들여써져서 보인다
- [x] 브랜치 안에서 또 "더 풀기"를 누르면 중첩 브랜치가 한 단계 더 들여써져서 보인다

## 수정 이력 — 브랜치 확장/복귀 방식 (사용자 피드백으로 재작업)
처음 구현: `drillTopic()`이 같은 topic 문제를 한 번에 5개 뽑아 브랜치를 미리 채움. "상위 흐름으로
돌아가기"는 분기 낸 지점의 **다음** 문제(`spawnIndex + 1`)로 이동.

문제 제기: (1) 미리 5개를 만들지 말고 지금 푸는 문제에서 한 번에 하나씩 뻗어나가야 함.
(2) 상위로 돌아가면 분기를 냈던(이미 푼) 문제로 먼저 돌아가야 하는데, 건너뛰고 있었음.

수정:
- `drillTopic()`은 이제 문제 1개로만 브랜치를 시작
- 브랜치 안에서 "다음 문제"를 누르면(`goNext`) 그 시점에 같은 topic 중 안 쓴 문제를 하나 새로 뽑아 붙임(지연 생성). 다 썼으면 자동으로 상위 복귀
- `popBranch`(자동/수동 복귀 모두)는 `spawnIndex + 1`이 아니라 `spawnIndex`로 이동 — 분기를 냈던 문제를 **이미 제출된 상태**(선택한 답 + 해설)로 다시 보여주고, 거기서 "다음 문제"를 눌러야 그 다음으로 넘어감
- 이를 위해 각 답변 기록을 `boolean`(정답 여부만) 대신 `{ selectedIndex, correct }`로 저장하도록 변경 (`src/lib/storage.ts`의 `AnswerRecord`)

## 추가 수정 — 분기점당 최대 10문제, 다 풀면 자동 상위 복귀
반복 허용으로 브랜치가 무한정 이어질 수 있게 됐으니, 대신 한 분기점(브랜치)당 최대
`MAX_BRANCH_QUESTIONS = 10`문제로 못박음. 10번째 문제까지 풀고 "다음 문제"를 누르면
더 안 뽑고 무조건 상위 흐름으로 자동 복귀 (`goNext`).

## 추가 수정 — 브랜치 안에서 같은 topic 문제 다 쓰면 자동으로 상위 복귀하던 버그
집계함수는 문제가 8개뿐이라, 브랜치 안에서 8문제를 풀면(그 topic의 안 쓴 문제를 다 써버려서)
자동으로 상위 흐름으로 튕겨 나가는 문제가 있었음. 사용자가 원하는 건 "상위로 돌아가기"를
직접 누르기 전까지는 계속 풀 수 있는 것 — 안 쓴 문제가 없으면 그 topic 안에서 반복해서
문제를 다시 뽑도록 수정 (`goNext`). 반복되는 문제 때문에 사이드바 렌더링 키를 `q.id`에서
`${branch.id}-${i}`로 변경(같은 문제가 한 브랜치 안에 두 번 나올 수 있어서 id만으로는 키가 겹침)

## 추가 수정 — 브랜치 깊이 5 제한 + 조상 전체와 겹치지 않는 새 주제만 추천
- 브랜치 깊이(`Branch.depth`, 메인에서 갈라진 첫 브랜치=1)가 5에 도달하면 "더 풀기" 버튼을 아예 숨김
- 중첩 브랜치의 다음 주제는 직속 부모뿐 아니라 **조상 전체**(`ancestorTopics`)에서 이미 쓴 주제를 제외하고 고름. 추천할 새 주제가 없으면 버튼을 숨김 (현재 주제가 2개뿐이라 실제로는 깊이 3부터 버튼이 사라짐)
- 버튼 노출 여부와 버튼에 표시되는 주제가 어긋나지 않도록, 렌더링 시 `nextDrillTopic()`을 한 번만 호출해 `drillTarget`에 저장하고 클릭 핸들러에도 그대로 넘김 (매번 다시 계산하면 랜덤이라 표시/생성이 달라질 수 있었음)

## 추가 수정 — 메인 흐름도 미리 안 만들기 + 중첩 브랜치는 다른 주제로
- 메인 흐름(20문제)도 처음부터 다 만들어두지 않고 1번 문제부터 시작, "다음 문제"를 누를 때마다 하나씩 생성 (브랜치와 동일한 지연 생성 패턴)
- 브랜치 안에서 또 "더 풀기"(중첩 브랜치)를 누르면 같은 주제를 또 파고들지 않고 반드시 다른 주제로 전환 (`nextDrillTopic()`). 첫 번째 브랜치(메인 흐름에서 갈라지는 것)는 막힌 그 개념을 그대로 더 푸는 것이므로 기존대로 같은 주제 유지

## 건드릴 파일
- `src/app/sqld/page.tsx` — `Branch.results` 타입, `submitAnswer`, `drillTopic`, `goNext`, `popBranch`, 상태 점 렌더링
- `src/lib/storage.ts` — `AnswerRecord` 타입 추가, `SavedBranch.results`/`SavedSession.mainResults` 타입 변경

## 확인 방법
- 문제 풀고 "더 풀기" → 브랜치에 문제 1개만 생기는지
- 브랜치 안에서 "다음 문제" 누를 때마다 하나씩 늘어나는지
- "상위 흐름으로 돌아가기" 누르면 분기 냈던 문제가 (제출된 상태로) 다시 보이고, 거기서 "다음 문제"를 눌러야 진짜 다음으로 넘어가는지
- 중첩 브랜치(브랜치 안에서 또 더 풀기)도 같은 방식으로 동작하는지
