# 기능 3: 왼쪽에서 메인 흐름과 브랜치를 볼 수 있다

## 완료 조건
- [x] 왼쪽 사이드바에 메인 흐름(1~20) 목록이 보이고, 지금 위치가 표시된다
- [x] "더 풀기"로 브랜치를 만들면, 그 브랜치가 스폰된 메인 문제 아래에 들여써져서 보인다
- [x] 브랜치 안에서 또 "더 풀기"를 누르면 중첩 브랜치가 한 단계 더 들여써져서 보인다

## 수정 이력 — 브랜치 확장/복귀 방식 (사용자 피드백으로 재작업)
처음 구현: `drillTopic()`이 같은 topic 문제를 한 번에 5개 뽑아 브랜치를 미리 채움. "상위 흐름으로
돌아가기"는 분기 낸 지점의 **다음** 문제(`spawnIndex + 1`)로 이동.

문제 제기: (1) 미리 5개를 만들지 말고 지금 푸는 문제에서 한 번에 하나씩 뻗어나가야 함.
(2) 상위로 돌아가면 분기를 냈던(이미 푼) 문제로 먼저 돌아가야 하는데, 건너뛰고 있었음.

수정:
- `drillTopic()`은 이제 문제 1개로만 브랜치를 시작
- 브랜치 안에서 "다음 문제"를 누르면(`goNext`) 그 시점에 같은 topic 중 안 쓴 문제를 하나 새로 뽑아 붙임(지연 생성). 다 썼으면 자동으로 상위 복귀
- `popBranch`(자동/수동 복귀 모두)는 `spawnIndex + 1`이 아니라 `spawnIndex`로 이동 — 분기를 냈던 문제를 **이미 제출된 상태**(선택한 답 + 해설)로 다시 보여주고, 거기서 "다음 문제"를 눌러야 그 다음으로 넘어감
- 이를 위해 각 답변 기록을 `boolean`(정답 여부만) 대신 `{ selectedIndex, correct }`로 저장하도록 변경 (`src/lib/storage.ts`의 `AnswerRecord`)

## 건드릴 파일
- `src/app/sqld/page.tsx` — `Branch.results` 타입, `submitAnswer`, `drillTopic`, `goNext`, `popBranch`, 상태 점 렌더링
- `src/lib/storage.ts` — `AnswerRecord` 타입 추가, `SavedBranch.results`/`SavedSession.mainResults` 타입 변경

## 확인 방법
- 문제 풀고 "더 풀기" → 브랜치에 문제 1개만 생기는지
- 브랜치 안에서 "다음 문제" 누를 때마다 하나씩 늘어나는지
- "상위 흐름으로 돌아가기" 누르면 분기 냈던 문제가 (제출된 상태로) 다시 보이고, 거기서 "다음 문제"를 눌러야 진짜 다음으로 넘어가는지
- 중첩 브랜치(브랜치 안에서 또 더 풀기)도 같은 방식으로 동작하는지
