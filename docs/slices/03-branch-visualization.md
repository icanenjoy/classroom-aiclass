# 기능 3: 사용자가 왼쪽에서 메인 흐름과 브랜치를 한눈에 볼 수 있다

세션 중간에 우선순위가 당겨져서 기능 3·4보다 먼저 만듦 (사용자 확인됨).

## 완료 조건
- [ ] 왼쪽 사이드바에 메인 흐름(1~20) 목록이 보이고, 지금 위치가 표시된다
- [ ] "더 풀기"로 브랜치를 만들면, 그 브랜치가 스폰된 메인 문제 아래에 들여써져서 보인다
- [ ] 브랜치 안에서 또 "더 풀기"를 누르면 중첩 브랜치가 한 단계 더 들여써져서 보인다

## 안 되는 경우
- 브랜치를 다 풀거나 "상위로 돌아가기"를 누르면 → 스폰된 지점 바로 다음 문제로 자동 복귀

## 이번에 안 하는 것
- 픽셀 단위로 정교한 git-graph 스타일 연결선 (연결선 대신 들여쓰기 트리로 단순화)
- 사이드바에서 과거 브랜치를 클릭해 다시 들어가는 기능

## 건드릴 파일
- 고칠: `src/app/sqld/page.tsx` (상태를 큐 → 메인흐름+브랜치 스택 구조로 변경, 사이드바 추가)

## 확인 방법
- 문제 풀고 "더 풀기" → 사이드바에 브랜치가 들여써져서 나타나는지, 그 안에서 또 "더 풀기" 눌러서 중첩되는지, 다 풀면 메인으로 자동 복귀하는지 직접 클릭

## 물어볼 것 → 임의로 결정한 사항 (변경 필요하면 알려주세요)
- 사이드바는 픽셀 정밀 그래프 대신 **들여쓰기 트리**(main 아래 브랜치, 그 아래 중첩 브랜치)로 단순화해서 구현
- 브랜치 안에서도 언제든 "상위 흐름으로 돌아가기" 버튼으로 다 안 풀고도 나올 수 있게 함 (사용자가 "이해될 때까지"라고 했으므로 강제로 다 풀게 하지 않음)
- 같은 문제도 여러 번 나올 수 있음 (브랜치 풀 구성 시 이미 쓰인 문제도 후보에 포함)
